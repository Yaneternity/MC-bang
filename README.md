# Lets Go Cobblemon Master [6.0.2fix + 科技]

整合包下载（GitHub Release 分卷）。

## 为什么是分卷？

GitHub 限制：

- 仓库内单个文件最大 100 MB（超过会被拒绝推送）
- Release 附件单个最大 2 GB
- 本整合包压缩后约 4.3 GB，所以拆成 3 个分卷发布

## 下载

到本仓库的 **Releases** 页面，下载全部 3 个分卷文件：

```
LetsGoCobblemon_Master_6.0.2fix_Tech.7z.001
LetsGoCobblemon_Master_6.0.2fix_Tech.7z.002
LetsGoCobblemon_Master_6.0.2fix_Tech.7z.003
```

## 解压 / 还原

把 3 个分卷放在**同一个文件夹**里，按顺序解压两层：

1. 右键点击 `LetsGoCobblemon_Master_6.0.2fix_Tech.7z.001` → **7-Zip → 提取到当前文件夹**
   （7-Zip 会自动合并 3 个分卷，得到 `LetsGoCobblemon_Master_6.0.2fix_Tech.7z`）
2. 再右键这个 `.7z` 文件 → **7-Zip → 提取到当前文件夹**
   （得到原始整合包 `Lets go cobblemon master [6.0.2fix+科技].zip`）

> 注意：不要单独解压 002 / 003，也不要改名。
> 没有 7-Zip 的话：https://www.7-zip.org/

## 安装

用 PCL2（Plain Craft Launcher 2）或 HMCL「安装整合包」选择解压出的 zip 即可。
